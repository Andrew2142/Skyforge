Skyforge

Delegate your prompts across multiple AI agents

Work from a single chat window while one manager delegates your prompts to a floor of AI sub-agents.

Tired of juggling multiple CLI windows? Skyforge lets you work from a single chat window while your prompts get delegated to sub-agents, all overseen by one manager — a simpler way to get work done than switching windows every few seconds. Just keep feeding the manager tasks, and it delegates to sub-agents like a factory floor.

Nothing about it is loud. There are no dashboards to babysit and no progress bars to watch. You speak in tasks; it answers in a single line when each one is done, and gives you the whole picture only when you ask for it.

What it does

The work is divided among three roles, and each stays firmly in its lane.

The Manager is the main conversation. It owns intake, breaks each request into tasks, dispatches them, watches for completions, and reports back. It never does the task work itself — it only coordinates, so nothing moves without your approval.

The Workers are background agents, one task apiece, carried end to end and returned as a structured report. Any task that writes files runs inside its own isolated worktree, so several workers can labour at once without ever clobbering each other or your working tree.

The Board is a durable ledger kept in your repository at .skyforge/board.json. Every change flows through a single command, and it survives a restart — so the shop always remembers exactly where it stood.

The board

At any moment the board holds every task and the single state it is in. A glance tells you what is running, what is finished, and what has stalled waiting on you.

Installing

Skyforge is a Claude Code skill. The simplest way to add it: in Claude Code — or any coding agent — hand over the repository and let it do the work for you.

Say this to your assistant Please install this skill:https://github.com/Andrew2142/Skyforge

It reads the repository and runs the one-line installer on your behalf. Or run it yourself: 

curl -fsSL https://raw.githubusercontent.com/Andrew2142/Skyforge/main/install.sh | bash

The installer places the skill under ~/.claude/skills/skyforge and its worker under ~/.claude/agents. Start a fresh session, and the shop is open.

How to use it

One loop runs the whole shop. The first two steps wait on your word; the rest turn on their own.

  1. Hand over a task

    Say “skyforge” and describe the work. The board initialises itself, once, in the current repository.

  2. Approve the plan

    Skyforge proposes a breakdown — which tasks edit files, which only read, and what depends on what — then stops. Nothing is dispatched without your yes.

  3. Watch it dispatch

    Approved tasks launch as concurrent workers, and anything that writes files is given its own isolated worktree.

  4. Be reported to

    Each worker finishes with a report; the board updates and you receive a single line, not a wall of text.

  5. Ask for the picture

    Say “how’s the factory?” for a grouped status: what runs, what is blocked, and what is ready for your review.

  6. Keep feeding

    Drop in new tasks whenever you like. Workers already in flight carry on untouched; the loop simply widens to hold more.

To begin

Any of these will wake the shop. Speak plainly; the manager is listening for the intent, not the exact words.

  • skyforge
  • delegate this to the team
  • spin up the factory
  • how’s the factory doing?

And every task, from first breath to last, lives in one of five states:

queued·running·done·blocked·failed
